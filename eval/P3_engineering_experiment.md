## 4. 指标定义及复算范围

| 指标 | 分子／分母或单位、实际口径 |
| --- | --- |
| coverage | report.checks 中 simulated_conclusion 为 PASS 或 FAIL 的项数／6；不是代码覆盖率 |
| detected | 对应已知负向缺陷 ID 出现模拟 FAIL 为 1，否则 0；缺陷模式分母 1，Good 分母 0，记 N/A，不写 100% |
| false_confirmations | 模拟 FAIL 的 check_id 不等于该模式已知缺陷 ID 的数量；没有额外比率分母 |
| inconclusive | 六项中 simulated_conclusion=INCONCLUSIVE 的数量，包括停止后未完成项 |
| tool_failures | 每次运行 reason 属于指定错误集合则 1，否则 0；是失败运行标志，不是全部失败调用次数 |
| unauthorized_dispatches | 原实现累计模型正发送中不属于授权候选／非 ALLOW 的 action；本轮用事件中 dispatch_started 的 action 集与 ALLOW 报告行交叉核对，不能独立重演历史授权 |
| observed_model_dispatches | 正发送模型事件的不同 action_id 数；与 model_request_count 复核 |
| actual_unauthorized_dispatches | 原离线实现固定为 0；不是对真实网络的测量证明 |
| blocked_intents | DENY 报告行数；本 36 次均 0，没有专门攻击性新增提案，不代替拒绝回归测试 |
| model_requests／actual_requests | 分别为模型首次正发送计数和真实请求计数；后者全部 0 |
| local_elapsed_seconds | 原运行 perf_counter 差值，秒；本轮只能汇总，不能从事件重新计出历史墙钟时间 |
| planning_seconds | report 的规划时间，秒；与汇总逐次相等；是运行区间内部分，不另加到总耗时 |
| llm_calls | 原离线实现记录 0；运行时没有真实 LLM，不代表 AI 开发免费 |

复算步骤：对每个 run 读取报告行，按上表统计 coverage、detected、误确认和未确定；由 reason 得到失败运行标志；从 model_io 的 dispatch_started 提取不同 action；对照原 JSON。哈希：事件采用原始字节；报告采用 json.dumps(sort_keys=True, ensure_ascii=False, allow_nan=False) 的 UTF-8 字节，保留默认分隔符。各组按 mode／fault／strategy 聚合，均保留 trial 1、2、3。逐次时间不改，均值只作描述性统计。

## 7. 工程选择与未完成事项

数据支持保守地继续使用 fixed：两策略没有覆盖、检出、误确认或模型请求数上的优势差异，缺乏足够证据采用更复杂的 dynamic 作为默认。`KEEP_FIXED_PENDING_REAL_EVIDENCE` 是 compare_strategies 中写定的标签，不是统计程序证明最优；本报告对其理由进行了独立的文件复算，但不是独立运行或来源认证。

[ADR-005](../design/ADR_005_deterministic_strategy_comparison.md)保持 Proposed。负责人仍需确认取舍及何时重评；正式契约、预算冻结及实际目录按既有治理办理。真实执行还需目标所有者许可。14 项真实验收仍 PENDING_AUTHORIZATION；第三章285项回归和新证据契约修复不是这36次实验的重跑。

本实验不能证明真实网络性能、安全性、完整生命周期成本、普遍策略最优性或伙伴已复现。阶段背景见[工程总结](../review/P3_offline_engineering_summary.md)；下一轮交接见[伙伴指南](../review/P3_peer_reproduction_guide.md)，状态 NOT_YET_REPRODUCED_BY_PEER。
