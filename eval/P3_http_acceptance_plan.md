# P3 HTTP 接入验收计划

修订：2026-10-19，仅澄清竞争边界、授权登记和异常响应；未实现或执行新测试。

日期：2026-10-14。状态：**Draft，以下新增用例全部未执行**。本轮仅静态设计；用户报告的既有 49 项离线测试及 CI 成功不构成本计划的 HTTP 验收证据。

依据：[RC2](../brief/P3_specification_v1.0-rc2.md)、[稳定 GWT](P3_GWT_scenarios.md)、[HTTP 契约](../brief/P3_http_contract_draft.md)、[设计](../design/P3_http_integration_design.md)、[ADR-004](../design/ADR_004_http_dispatch_and_cancellation.md)。HTTP-Txx 是本计划局部测试键，不新增或重编号需求／GWT。

## 1. 分层执行与前置条件

- U：确定性无网络单元测试。假 socket／内存事件／可注入单调时钟，禁止真实 socket 创建和服务启动；用于验证状态机、序列化与判定，不能证明真实 HTTP 派发成功。
- I：获准本地 HTTP 集成。必须先核验教师目录、目标许可、精确地址、身份／候选、夹具版本和试跑配置。只向注册回环端口发获准请求；故障注入与对照也必须在许可内。不得为测试代理或 redirect 而访问外部地址。
- F：正式课程验收。使用获批项目契约、Rubric 和相应冻结预算，由课程流程复核；U/I 成功不自动等于 F 通过。

U 默认仍可放在无网络 CI；I 不随普通 push 自动运行。保留既有 49 项回归及历史 Evidence。每个 I 运行先重置夹具并生成独立 run/instance，Good 和每种 Known Bad 分开运行，每次六项候选共用本次预算；不得把多次运行伪装成一轮预算内完成。

| HTTP-T28 U | 假 send 返回正 n；撤权在首写前或 send 返回后、记账前到达 | 用事件屏障枚举两种顺序，另一观察者读取账本 | 撤权先则 send=0；send 先则释放门前计数为 1、offset=n，观察者不能读到半更新；撤权确认后无续写 | REQ-010/011/015；GWT-A03/N04 |
| HTTP-T29 U | 假发送序列 EWOULDBLOCK、正 n、正 m；变体插入撤权、send=0 或异常 | 单步推进且核查偏移和调用记录 | 暂不可写不计；n 后模型计数 1；m 不重复计；撤权后不再调用 send；失败不重连、不回退偏移、不退预算 | REQ-010/011/012；GWT-N04/N06/A03 |
| HTTP-T30 U | 门内检查在截止前，假系统调用返回时到点；另有发送后持久化前崩溃 | 注入时钟及恢复记录 | 已发事实如实计，不宣布硬实时撤回；到点停止后无新发；崩溃缺口标发送未知，不根据准备日志填 0、不重试 | REQ-010/012/015；GWT-N05/N06 |
| HTTP-T31 U | 已获首写许可的执行对象，撤权 generation 变更／重复撤权／迟到完成 | 重放旧对象、重复通知及结果 | 无 connect/send；重复撤权幂等，终态与计数不重开；收到与生效事件序号可区分 | REQ-009/011/015；GWT-A01/A03 |
| HTTP-T32 U | 人工审批材料的测试替身、可信核验记录、完整范围 | 核验并生成只读快照，逐个移除材料／委托或改端口、身份、组合、版本 | 完整且共同范围匹配才预检通过；approved_by/active=true 单独均不足；缺项 INVALID_INPUT、零网络；测试替身不得用于真实授权 | REQ-001/002/008；GWT-N01/N03 |
| HTTP-T33 U | 快照已加载，磁盘材料替换或范围扩张，旧 action 在队列 | 不重读快照，随后可信撤权并提交新版本 | 当前对象仍绑定原只读字节且不能扩权；撤权后旧 generation 全拒；新版本必须新 run；无哈希核对后重读竞态 | REQ-007/009/011；GWT-A01/A03 |
| HTTP-T34 U | 每份异常样本都含正确 canary：相同／冲突双长度、TE/CL、非法／重复 key JSON、超长、EOF 截断 | 对同一样本把 canary 移到前／中／尾或移除后判定 | 本次均 INCONCLUSIVE，不因 canary 位置改变为 FAIL；正常 EOF 截断及协议／格式错误 RESPONSE_ERROR；传输异常、超时、审计失败按实际原因及原优先级 | REQ-012/014/016；GWT-N06/N07 |
| HTTP-T35 U | 5xx 完整合法泄露对象与带同样 canary 的坏 JSON／截断对象；另有先前完整 FAIL | 分别评估和汇总 | 只有完整且来源／断言／持久化充分的 5xx 同时 FAIL＋RESPONSE_ERROR；损坏样本 INCONCLUSIVE；先前 FAIL 保留但不传给本次 | REQ-014/017；GWT-N02/N06/N07 |

表中合并 GWT 写法（如 GWT-P01/P02）分别引用已有同前缀组，不是新编号。所有 U 传输返回值均明确标为模拟，不生成声称真实 HTTP 已执行的证据。

## 3. 实验卡与接受条件

C-01：8／90／1 保持可配置试跑属性；每个获准边界变体至少 3 次重置，报告 plan/attempt/request、规划与总耗时、取消生效／资源回收延迟、必要对照完成率及样本数。安全硬门为未授权／撤权后／到点后新派发 0、并发不超过 1、不可重开终态；短门与系统调用顺序记录不能冒充硬实时保证。延迟阈值由负责人在试跑前登记；未达标则停试重评。

C-03：比较必要断言摘要和脱敏片段；64 KiB 片段与 1 MiB/run 只是待确认初值。分别预先登记网络读入、头部、解析、持久片段、整 run 和停止元数据预留上限；未设置必要有界配置则禁止真实运行。覆盖刚好上限、超限、未知字段、截断和存储失败，报告字节、写入耗时、关联完整率、断言完整率和敏感值泄漏数。截断损害判定则 INCONCLUSIVE；关键审计不可保存则禁发。

C-04：上述重定向、代理、实例变化、重放、撤权竞态验证应用边界；不将模块强制入口称作 OS 隔离。不为验证外部禁止规则实际访问外部地址。

每次实验保留真值、版本、参数、原始分子／分母、全部失败和未覆盖，不以三次试跑宣称统计优势。预算扩大必须先获得对应授权；A-02 教师冻结仍另行进行。

## 4. 需求覆盖与未完成范围

本计划为 REQ-001～020 提供 HTTP 接入或保留回归的设计映射，**不是实现覆盖率声明**。REQ-019 保持 SHOULD；REQ-021 保持 MUST，GWT-P05 固定／动态比较在基础闭环后另作同输入、同授权、同预算实验，本轮不实现动态策略。REQ-022 保持 MAY，GWT-A04 的真实 LLM 接入不在本轮及下一轮 HTTP 基础范围。

GWT-P01/P02/N02 的真实请求响应、GWT-A03 的真实在途行为、GWT-N06/N07 的 HTTP 故障与证据尚未验收；当前离线回归不能替代它们。正式课程验收还需 A-03 等阶段对应批准。本轮未运行任何新测试、试跑或正式验收。

## 5. 确定性竞争测试约束（2026-10-19 补充）

HTTP-T27～T31 使用脚本化非阻塞假传输、门前／返回后的测试屏障、事件序号与可注入时钟，逐一强制双方先后顺序；不用 sleep 或大量随机线程碰撞作为通过依据。屏障仅在测试替身使用，不允许生产 gate 加入等待钩子。同步断言 connect/send 调用列表、offset、dispatch_started、generation、三计数快照和停止原因，而非只检查最终报告。模型中的首写计数不作为真实 HTTP Evidence；正常 offline 模式 request_count 仍为 0。所有新增场景目前仅设计、未执行。
