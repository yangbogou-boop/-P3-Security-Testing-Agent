# ADR 003：本地模拟执行、证据组织与工程试跑方案

日期：2026-10-12。

## Status

**Proposed／待项目负责人确认**。本轮只是推荐，没有把新框架、凭据配置、证据上限或实验结论标为 Accepted。课程审批事项仅按 [治理登记](../brief/P3_decision_governance.md) A 类处理；已有黑盒方向与已审核计数规则不重新等待教师批准。

当前候选规格：[Specification V1.0-RC2](../brief/P3_specification_v1.0-rc2.md)，2026-10-14 同步引用；本 ADR 仍为 Proposed，不因版本升级自动接受方案。

## Context

当前只有模拟扫描意图和结果，没有 HTTP Executor、可响应的模拟 API 或完整审计链。要在已有 HTTP JSON、模拟 Bearer Token、只读及强制 Controller 入口约束下形成可复现的最小闭环。课程要求先纯模拟流程再开放教师批准的本地动作；模块分离不能宣称物理隔离。

## Alternatives

| 方案 | 需求／复杂度 | 安全／成本／可复现与维护 |
| --- | --- | --- |
| 标准库 HTTPServer、HTTP 客户端、JSON 配置和文件证据 | 足够承载少量只读端点，无新增依赖 | 零外部服务费用、容易离线重置；路由校验、超时及取消边界需自行实现，不能用于宣称生产级服务。 |
| FastAPI／Flask 与外部 HTTP 客户端 | 声明式路由／验证与更成熟组件 | 多依赖及版本管理，当前小范围收益未测；端点规模或契约复杂度增长时值得重评。 |
| 数据库与完整平台／GUI | 查询和交互能力更强 | 引入迁移、权限、部署与维护负担，不是首版闭环必需。 |
| 容器／独立进程执行 | 可增强操作系统边界 | 环境准备成本较高；容器名不证明隔离，宿主挂载与 Docker socket 可能破坏边界。真实或不可信工具出现时须单独设计。 |
| 仅伪造成功消息 | 开发最少 | 无实际 HTTP 与权限证据，不能满足 REQ-013，排除。 |

## Decision

建议采用标准库 HTTPServer 承载回环地址模拟 API，配置化模拟身份、角色、对象及 Good／Known Bad 夹具；命令行加载可信契约、权限矩阵和授权配置。标准库 HTTP 客户端仅由 Controller 强制入口派发已登记请求，不接受任意 URL／Shell，禁止代理、重定向和原始 Token 日志。

先提供纯模拟响应路径以验证状态、预算和撤权，再在 A-01 目录批准及目标授权齐备后开放本地 HTTP。Controller 绑定不可由 Planner 修改的政策快照，可信撤权入口只减权。具体运行机制的竞态与取消延迟必须测量；同步请求不承诺瞬时取消。

建议每个 run 独立目录：JSONL 事件、JSON Manifest 和有限报告，使用唯一 run／check／attempt／evidence ID。保留既有 evidence 原样，禁止同秒覆盖；记录拒绝、错误、停止、实际请求与未覆盖，脱敏并说明截断。这是产品内部格式，不能替代教师冻结的评价输出 Schema。

按治理登记 C-01～04 进行预算、策略及证据试跑。8／90／1 保持教学试跑属性；证据片段 64 KiB／run 1 MiB 为新工程建议，未确认且未测，不作为已生效限制。最终班级预算由教师试跑后冻结。

## Rationale

优先满足受控执行、可判定权限、可复现证据和低维护成本。标准库小切片可以使所有依赖与数据留在本地，减少非核心平台工作；确定性策略允许直接比较检查收益和规划成本，不需要付费 LLM。实验记录必须报告覆盖与成本，不能把少做任务直接包装成效率优势。

## Consequences

- 收益是依赖少、无商业服务成本、夹具易重置和证据易检索；这些是工程理由，尚未有性能实验数据。
- 代价是自行维护字段验证、协议错误处理、证据关联和同步请求取消边界；模块设计不能防任意同进程恶意代码。
- 存储／超时失败时先安全停止并报告不足；保留有限结论，不用模拟成本或消息代替实际结果。
- 框架及格式的实施等待负责人确认；正式课程合同、目录、预算及评分权限仍按 A 类，不以 Accepted 工程 ADR 绕过。

## Reconsideration

契约变复杂、标准库代码难维护、复现或停止试跑失败、必要证据经常被截断时重评框架与证据方案；动态无同目标质量／成本收益时保留固定 Baseline。接入实际系统或第三方不可信工具、需要进程权限隔离时重新评估架构并取得授权，不自动扩大当前范围。接受条件及逐次试跑设计见治理登记 C 类；未有数据不得宣称任何替代方案更优。
