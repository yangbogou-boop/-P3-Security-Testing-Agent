## 2. 设计概要与待确认技术事项

首轮建议六项检查：匿名、对象所有权、角色权限各一负向检查和一合法对照；每项独立计预算。用完整 JSON 断言与对照支持 PASS，泄露需独立充分证据，不能依据状态码或 Executor 成功判断安全。

建议采用 ADR-004 的分离状态机和单 I/O 所有者。现有同步锁内假派发不可直接改成阻塞 HTTP。短 gate 统一最终许可、时间、撤权及首个成功发送字节的计数；等待不持锁，取消不能撤回已发送请求，迟到响应不升级未完成项。

负责人 B 类待确认：端口及六项契约、身份／断言、授权核验责任人、ADR-004、实际派发的实现微边界、窄 HTTP 协议范围。所有候选仍 Draft／Proposed，不把 ADR-003 Accepted 扩大为本 ADR 自动获批。

C 类待试跑：取消延迟、网络读入与存储限制、64 KiB／1 MiB 建议、8／90／1 合理性及维护成本。无实验数据，不宣称非阻塞方案性能更优。REQ-021 固定／动态比较继续 MUST，基础 HTTP 之后开展，未交付不能声称完整工程要求完成。
