# P3 V2 通用离线评价指标 v1

经独立校验的持久化合成证据是指标的唯一数据来源。调用 reviewed_metrics.evaluate(directory) 会在同一次 reviewed_evidence.verify(directory, include_facts=True) 调用中读取并校验三文件，之后只使用返回的事实。现有默认 verify(directory) 保留原返回结构。指标定义版本为 p3-reviewed-metrics-v1。数值比例以 0 至 1 表示，同时保留原始分子和分母。

## 3A 至 3B-2B 定义追踪

3A 原定义来自课程项目的《3A 评价指标定义审查》指标表 §7。3B-2B 定义依据负责人批准的指标口径。3A 对已归档实验的原始定义继续保留。只有定义、统计单位、证据门槛和运行条件都相同的结果才适合比较。

| 编号 | 3A 原公式或输出 | 3B-2B 定义、统计单位及原因 | 证据与缺值条件 |
|---|---|---|---|
| M1 | 报告候选与未完成项的并集 / 同一范围并集 | D/R，去重候选；消除分子分母同源导致的恒值 | 独立范围及关联最终断言；缺范围时无值 |
| M2 | 已登记槽位数 / 审核候选数 | U/R，去重候选；未知提案单列 | 审核全集与登记事件；缺范围时无值 |
| M3 | 去重 fixture_handled action 数 / 审核候选数 | H/R，去重候选；动作数保留为辅助统计 | 范围和关联的夹具处理记录；缺范围时无值 |
| M4 | 已处理槽位数 / 审核候选数 | D/P，去重候选；度量已处理项的可判定性 | 处理与最终断言关联；P 为空时为零分母 |
| M5 | ALLOW、DENY 各自 / 授权决策数 | 沿用决策比例；未评价槽位单列 | 授权计数重放；零决策时各比率无值 |
| M6 | PASS、FAIL、INCONCLUSIVE 各自 / 已处理数 | 三个互斥分桶，各自 / P；使用最终断言 | 已处理候选须能完整关联最终模拟结论 |
| M7 | 具有完成对照的负向项 / 负向全集 | 保留原比例语义 | 对照全集无独立证据，NOT_CHECKABLE |
| M8 | 准备/审核范围、接受/准备、消费/接受、处理/消费 | 保留各阶段比例及独立计数，另列取消、中止、失败 | 14 项计数重放及交付关联；旧 V2 只给可复核的局部比例 |
| M9 | 登记槽位数 / max_checks | S/max_checks，未知提案也消耗预算 | 同次验证的预算与槽位；旧 V2 缺预算时无值 |
| M10 | 完整性二元标记 | 直接报告完整性及审计缺口 | 预期事件总数无独立证据，分子、分母和比率均为 null |
| M11 | 取消与中止的原因分类 | 仅对持久化关联支持的原因计数；另列不可核验声明 | 事件及报告关联；缺证据时无值 |
| M12 | 缺少持久化耗时 | NOT_MEASURED | 无可重放时间戳 |
| M13 | 缺少独立真值 | NOT_APPLICABLE | 无可核验真值及对应分母 |

R 为审核全集，U 为有效已提交候选，H 为具有完整夹具处理关联的候选，P 为已处理审核候选，D 为有明确 PASS 或 FAIL 的审核候选。上述集合按候选 ID 去重。S 是占用预算的登记槽位。授权分布的单位为决策，派发漏斗同时保留其事件重放计数。

## F1 指标事实一致性

M1、M4 和 M6 依据同一次校验中关联的响应投影、断言及最终结论。已核验分母在缺值时仍保留。缺少对照的断言只能给出 INCONCLUSIVE。延迟解决必须承接同一动作先前的 MISSING_CONTROL，并且在正向对照通过之后。证据未持久化具体对照候选 ID，评价只能核验该顺序与协议形状，无法独立证明对照身份或外部执行事实。矛盾的断言与结论标记为 EVIDENCE_INCONSISTENT，证据不足标记为 NOT_CHECKABLE。两种情况均保留其他可独立计算的指标。

M11 以可关联的取消或中止槽位计数。重复的报告条件不增加计数。有撤权关联时，其他停因不得替代撤权。没有撤权关联时，事件、报告主原因和首个停止条件须一致。无法核验的声明与已核验值分别列出。

## F2 类型与诊断约定

直接和延迟结论共用响应投影形状检查。响应状态使用协议规定的整数，解析失败且没有状态时可为 null；布尔标志与响应字段遵循原投影类型。验证无效时，M1、M4、M6 的有效结论统计为空，同时保留已核验的分母及独立指标。此检查不改变既有证据协议。

指标事实按固定顺序去重整理各类诊断。ASSERTION_CONCLUSION_CONFLICT 优先，随后为 FINAL_CONCLUSIONS_UNVERIFIED 和 CONTROL_EVIDENCE_UNVERIFIED。受影响指标的 details.conclusion_issues 记录全部检测到的诊断，顶层 status 和 reason 继续给出主结论。

## 缺值、兼容性与信任边界

合法零值返回 0。零分母使用 null 和 ZERO_DENOMINATOR。验证失败时，指标可用性分别表达为 INSUFFICIENT_EVIDENCE 或 EVIDENCE_INCONSISTENT。通过整体门槛但缺所需事实时使用 NOT_CHECKABLE。分布和漏斗的比率在各自子项中给出。

旧 V2 保留原校验流程，范围依赖指标不推算分母。V1 继续使用自己的历史展示与评价入口。approval_verified、source_authenticated 和 runtime_authorisation_verified 始终为 false。模拟结果仅适用于 NO_NETWORK_SIMULATION。审核预算的内部一致性和持久化校验的结果都不能用于确认外部批准或真实系统安全。
